# 縁取り（内側・部分） for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-PartialInnerOutline.svg)](https://github.com/routersys/YMM4-PartialInnerOutline/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、素材の輪郭から内側へ向かう縁取りを描き、その縁取りを帯で決めた範囲だけに残して元の映像に重ねる映像エフェクトプラグインです。
履歴フレーム、参照画像、学習済みモデルを使わず、入力された一枚の映像だけを処理します。
結果は設定と素材の画素から決定論的に決まり、同じ設定では常に同じ絵になります。
太さ、品質、なめらかさ、帯の方向、帯の中心位置、帯の幅、エッジのやわらかさ、不透明度、ぼかしの9項目はアニメーションに対応しています。

## 概要

本プラグインはYMM4の映像エフェクトとして動作し、エフェクトの種類一覧では「縁取り（内側・部分）」として表示されます。カテゴリは装飾です。

素材の不透明な部分の輪郭から、「太さ」の距離だけ内側までを縁取りにします。縁取りは素材の内側だけに描き、素材の外側へははみ出しません。縁取りを残す範囲は、向きと位置と幅を持つ帯で決めます。帯から離れた場所には縁取りを描かないので、輪郭の一部だけに縁取りを付けられます。

縁取りは次の順で作ります。

1. 素材の透明な部分を、素材の内側へ「太さ」の距離だけ広げます。
2. 広げた結果を、「なめらかさ」の幅で縁取りの形に変えます。
3. 縁取りの形に、帯と「不透明度」を掛けます。
4. 「縁の模様」のブラシを、縁取りの形で切り抜きます。
5. 「ぼかし」をかけ、素材の不透明度で切り取ります。
6. 「合成モード」で、元の映像に重ねます。

結果は設定と素材の画素だけから決まります。時間値と乱数は使いません。同じフレームは何度描いても同じ結果になります。

処理はDirect2Dのカスタムピクセルシェーダーと標準のエフェクトが行います。CPUへの画素の読み戻しは行いません。

このエフェクトはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-PartialInnerOutline/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として「縁取り（内側・部分）」を選択してください。

## 主な機能

### 1. 縁取りの太さと形

「太さ」は素材の輪郭から縁取りの内側の端までの距離で、単位は画素です。0.1画素単位に丸めて使います。

素材の透明な部分は、太さをいくつかの段に分けて広げます。段の長さは、1、2、4、8のように倍に増える長さと、最後に残る長さです。太さ3は2と1に、太さ5は2と2と1に分かれます。長い段から順に、画素ごとに、その画素と、そこから段の長さだけ離れた円周上の点を調べます。その中でいちばん透明な点の透明の度合いが、その画素の新しい値になります。段を重ねると、縁取りは輪郭から太さの距離まで届きます。

「角縁取り」をONにすると、円周の代わりに正方形の周を調べます。輪郭から斜めに離れた位置にも、縦と横に離れた位置と同じ距離まで縁取りが届くため、素材の凹んだ角のまわりで、縁取りの内側の端が丸まらず、角張ります。

### 2. 品質

「品質」は段ごとに調べる円周上の点の数の上限です。点は、隣り合う点の間隔が約1画素以内になる数だけ置きます。段が長いほど必要な点の数が増え、上限を超える分は切り詰めます。既定の64では、長さが約10画素までの段で、間隔を1画素以内にできます。「角縁取り」では正方形の周が長いので、約5画素までの段が同じです。

点の数を切り詰めると、点の間隔が1画素より広がります。間隔が広がるほど、点の間に入る細い隙間や小さな穴を見落としやすくなり、縁取りの太さも向きによって不揃いになります。「品質」を下げると処理は軽くなります。段が短いと、必要な点の数が上限に届かないので、「品質」を変えても結果は変わりません。

### 3. なめらかさ

広げた結果は各画素の透明の度合いを0から1で表した値で、0.5を中心にこの値が0から1へ変わる幅が「なめらかさ」で決まります。100%では0から1までなだらかに変わり、縁取りの内側の端がなめらかです。0%にすると0.5で切り替わり、端が階段状に見えます。

### 4. 帯で縁取りを残す範囲を決める

帯は縁取りを残す範囲で、帯から離れた場所には縁取りを描きません。帯の基準は、このエフェクトに入る映像を囲む矩形の中心です。素材の外側に透明な余白があるときは、余白も含めた矩形が基準になります。

「帯の方向」は帯を動かす軸の向きです。0°が右、90°が上で、帯はこの軸に垂直に延びます。既定の90°では帯が横に延びます。「帯の中心位置」と「帯の幅」は、この軸に沿って測ります。

長さの基準にするのは、軸に沿って測った、矩形の中心から軸の向きにいちばん遠い角までの距離です。この距離を半幅と呼びます。

- 「帯の中心位置」は帯の中心を、矩形の中心から軸の向きへ動かす量です。半幅に対する割合で、0%で矩形の中心、100%で軸の向きの端、-100%で反対の端になります。
- 「帯の幅」は縁取りを残す帯の幅です。半幅に対する割合で、100%で半幅と同じ幅、200%で矩形全体を覆います。
- 「エッジのやわらかさ」は帯の両端をぼかす幅です。縁取りは、帯の端から内側と外側へ、帯の幅の半分にこの割合を掛けた距離だけ、少しずつ弱まります。0%では帯の端がはっきりします。

既定の設定では、幅100%の帯が矩形の縦の中央に横向きにあり、矩形の高さの半分の範囲に縁取りが残ります。

### 5. 縁の模様と合成

「縁の模様」は縁取りを塗るブラシです。単色のほか、YMM4のブラシの種類から選べます。ブラシは縁取りの形で切り抜きます。ブラシの模様は、エフェクトに入る映像を囲む矩形に、ぼかしで広がる範囲を加えた矩形へ敷きます。

「不透明度」は、縁取りの濃さに掛けます。「合成モード」は、縁取りを元の映像に重ねる方法で、YMM4の合成モードから選びます。

### 6. ぼかしと素材の外側

「ぼかし」は縁取りにかけるガウスぼかしの標準偏差で、単位は画素です。ぼかした縁取りも素材の不透明度で切り取るので、素材の外側へはにじみません。

ぼかすときは、素材の外側にも縁取りがあるものとして扱います。帯の内側では、輪郭のすぐ内側の縁取りが、ぼかしても弱まりません。

### 7. 縁のみ

「縁のみ」をONにすると、縁取りだけを表示し、元の映像を隠します。「太さ」「不透明度」「帯の幅」のどれかが0のときは縁取りを描かないので、素材と同じ大きさの透明な映像になります。

### 8. 映像の端

映像の外側は透明として扱います。素材が映像の端に接していると、その端にも縁取りが付きます。

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- Direct2Dのカスタムエフェクトを作成できない場合は、エフェクトを適用せず入力映像を表示します。
- 縁取りの形には、現在のフレームの不透明度だけを使います。色は使いません。履歴フレーム、外部画像、学習済みモデルも使いません。
- 縁取りは素材の内側だけに描きます。素材の外側へ広げる機能はありません。
- 「太さ」は最大500px、「品質」は最大256、「ぼかし」は最大1000pxです。
- 帯の基準は、このエフェクトに入る映像を囲む矩形です。素材の不透明な部分だけを囲む矩形ではありません。このエフェクトの前に映像を拡大や切り抜きすると、矩形が変わり、帯の位置も変わります。
- 素材の幅が「太さ」の2倍より細い部分は、全体が縁取りになります。素材の内側にある透明な穴の縁にも、縁取りが付きます。
- 円周上の点の間隔が1画素より広がると、点の間に入る細い隙間や小さな穴を見落とすことがあります。間隔が広がるのは、「品質」を下げたときと、段が長いときです。
- 半透明の画素では、縁取りの濃さに素材の不透明度が掛かります。

## 注意事項

- 処理負荷: 縁取りの形を求める計算は、各段で調べる点の数の合計に比例して重くなります。「太さ」を大きくするか「品質」を上げると、重くなります。入力の映像が変わるフレームでは、縁取りの形を計算し直します。「太さ」「品質」をアニメーションで動かすと、動かしている間もフレームごとに計算し直します。「角縁取り」を切り替えたときも、計算し直します。「なめらかさ」「帯の方向」「帯の中心位置」「帯の幅」「エッジのやわらかさ」「不透明度」「ぼかし」「縁の模様」だけを動かすときは、計算した縁取りの形を再利用します。
- 縁取りを描かないとき: 「太さ」「不透明度」「帯の幅」のどれかが0のときは、縁取りの計算も合成も行わず、映像をそのまま通します。「縁のみ」がONのときは、透明な映像になります。
- 再現性: 結果は設定と素材の画素だけから決まります。時間値と乱数は使いません。同じフレームは何度描いても同じ結果になります。
- 更新通知: エフェクトを最初に生成したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 不具合の自動送信: 想定していない例外が起きたときは、その内容を開発者へ自動で送信します。内容は「不具合の報告」に書いています。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。

## 不具合の報告

本プラグインは、想定していない例外が起きたときに、その内容を開発者へ自動で送信します。同意は求めず、常に送信します。

送信する情報は次のとおりです。

| 種類 | 内容 |
|---|---|
| 例外 | 型の完全名、メッセージ、スタックトレース |
| 発生位置 | モジュール名、関数名、ファイル名、行番号 |
| プラグイン | アセンブリ名、バージョン |
| 実行環境 | OSの名前とバージョン、.NETのバージョン、CPUのアーキテクチャ、論理プロセッサ数 |
| 識別子 | YMM4の起動ごとに決まるセッション識別子、報告ごとの識別子 |

メッセージとファイル名は、送信の前に置き換えを通します。置き換えるのは、Windowsのユーザー名、ユーザーフォルダー、AppDataのパス、マシン名、ドメイン名、メールアドレス、IPv4アドレスです。送信元のIPアドレスは受信側へ渡す手前で取り除いています。

映像の中身とプロジェクトの内容は送信しません。継続して個人を追跡する識別子も持ちません。セッション識別子はYMM4を起動し直すと別の値になります。

送信するのは想定していない例外だけです。YMM4が本プラグインのエフェクトを作るとき、フレームごとに更新するとき、入力をつなぎ直すとき、破棄するときと、Direct2Dがシェーダーの定数を書き込むときに起きた例外を報告し、その後はYMM4へそのまま渡します。更新の確認では、更新情報の取得と比較で起きた例外は報告しません。通知の文を組み立てて表示するときに起きた例外は報告し、YMM4へは渡しません。画面の操作やバックグラウンドの処理で未処理になった例外も報告しますが、本プラグインのコードが関わる例外に限ります。本プラグインの外で起きた例外は送信しません。

次の失敗は送信しません。

| 種類 | 例 |
|---|---|
| 効果をかけないだけで済ませるもの | Direct2Dのカスタムエフェクトを作成できないときに、エフェクトを適用せず入力映像を表示したとき |
| 更新の確認の通信の失敗 | manjubox.netとGitHubのどちらへも接続できない |

送信できなかった報告はYMM4のユーザーフォルダーへ退避します。次にYMM4を起動したあと、本プラグインのエフェクトを生成するか、同じくYMM4-Telemetryで報告する別のプラグインが動き始めると、退避した報告を1回の起動で10件まで送り直します。送信も再送も非同期に行うため、通信を待って起動と描画が遅くなることはありません。

実装は [YMM4-Telemetry](https://github.com/routersys/YMM4-Telemetry) をサブモジュールとして取り込んでいます。
